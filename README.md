# Hope-You-Like-It-2D-Plaformer-
2D Platformer is a heartfelt 2D platformer built with Godot 4.6, where players collect floating hearts to uncover a romantic story. Featuring smooth movement, parallax backgrounds, hazards, ladders, springs, and polished UI, the game blends emotional storytelling with classic platforming mechanics. ✨ Exported for Web Windows &amp; Android.
